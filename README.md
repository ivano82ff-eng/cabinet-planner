# Корпус

Планировщик корпусной мебели.

Откройте в браузере: https://ivano82ff-eng.github.io/cabinet-planner/

Ничего устанавливать не нужно. Подойдёт Windows, Mac, Linux и телефон.

## Как пользоваться

1. Выберите тип слева: **Тумба**, **Навесной**, **Пенал** или **Комод**.
2. Задайте ширину, высоту и глубину в миллиметрах. Можно двигать ползунок или вписать число.
3. В блоке **Наполнение** укажите толщину корпуса (16 или 18 мм), число полок, фасадов и ящиков, высоту цоколя.
4. Выберите материал корпуса. Цвет в 3D-сцене совпадает с выбранной плитой.
5. В блоке **Заказ** напишите название, заказчика и почту.
6. По центру крутится корпус. Зажмите левую кнопку мыши и поверните, колесо приближает. Галочка **Фасады** снимает дверцы и ящики, чтобы было видно полки. Если навести курсор на деталь, появится её имя.
7. Справа — три чертежа в миллиметрах (фасад, вид сверху, бок) и таблица деталей. Сумма слева — это плита и кромка видимых торцов. Петли, направляющие, крепёж и работа в неё не входят.
8. Нажмите **Сохранить**. Проект появится в списке **Сохранённые** на этом компьютере, в этом браузере. На другом компьютере списка не будет.
9. **PDF** открывает лист с чертежом и спецификацией. В окне печати выберите «Сохранить как PDF».
10. **DXF** скачивает раскрой для CAD. **SVG** скачивает чертёж.

Если размер выходит за допустимый предел, программа сама его ограничит и напишет предупреждение под ценой.

## Файл для Windows

Если нужна копия без интернета: скачайте [Korpus-windows.zip](https://github.com/ivano82ff-eng/cabinet-planner/releases/latest/download/Korpus-windows.zip), распакуйте и запустите `Korpus.bat`. Браузер откроется сам. Окно консоли не закрывайте: пока оно открыто, программа работает.

## Для разработки

```bash
npm install
npm test
npm run dev
```

Интерфейс: http://127.0.0.1:5173  
API: http://127.0.0.1:3001/api/health

Без `DATABASE_URL` проекты пишутся во встроенный Postgres, каталог `data/pglite`. Отдельная база:

```bash
docker compose up -d
```

`DATABASE_URL=postgres://planner:planner@localhost:5432/planner`. Секрет вебхука по умолчанию `dev-secret`. Пример есть в `.env.example`.

Заказ из WooCommerce создаёт тот же проект. В метаданных позиции нужны тип, ширина, высота или глубина — по-английски или по-русски. Пример:

```bash
curl -X POST http://127.0.0.1:3001/api/integrations/woocommerce ^
  -H "Content-Type: application/json" ^
  -H "X-WC-Webhook-Secret: dev-secret" ^
  --data-binary "@integrations/sample-order.json"
```

Сборка одним процессом: `npm run build`, затем `npm start`. Шрифт PDF — Roboto (Apache License 2.0), файл `server/assets/Roboto-Regular.ttf`.
